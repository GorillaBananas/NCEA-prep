AI marking

Biology, economics and geography answers are written in sentences. With AI marking on, each written answer is graded Not Achieved, Achieved, Merit or Excellence, with feedback on what to add. Without it, the student marks themselves against a model answer.

Advanced: use a proxy instead of a key

If you run the small proxy in tools/marker-proxy/, put its address here and leave the key empty. The key then stays on the proxy and never reaches this browser.

Setting it up (parent):

  1. Sign in at platform.claude.com and add some credit. US$5 covers several hundred marked answers.
  2. Create an API key just for this site. Set a low monthly spend limit on it.
  3. Paste the key here, on the computer your child uses, and press Save and test.

The key is saved only in this browser on this computer. Anyone who uses this browser could find it, so use a key with a spend limit, and remove it when exams are over. Written answers are sent to Anthropic's API for marking and are not stored by this site.
